# 동 키워드 80페이지 정적 사이트 (1차 시범)

- 20개 동 × 4개 서비스 = 80개 상세 HTML 페이지 + 홈페이지 1개
- URL: /gwangbok-dong-sewer/ 형태
- 참고 작업 사진 113개는 전달된 파일에서 WEBP로 변환함. 특정 지역의 실제 사례로 표시하지 않음
- 연락처, 업체명, 사업자 정보는 실제 운영 데이터가 제공되지 않아 임의로 기입하지 않음

## 배포 절차
1. `configure.py` 파일의 SITE_URL을 실제 연결할 HTTPS 도메인으로 수정하세요.
2. `python configure.py` 실행하면 canonical, sitemap.xml, robots.txt, naver-submit-urls.txt가 만들어집니다.
3. 이 폴더 전체를 정적 호스팅(Vercel 등)에 배포하세요. 루트 index.html이 사이트 메인입니다.
4. 배포 후 80개 URL 모두 200 응답인지, 이미지와 CSS가 정상적으로 표시되는지 확인하세요.
5. 실제 업체 정보·상담 경로·출동 가능 지역을 확인한 뒤 등록하세요.
6. 네이버 서치어드바이저에 소유확인 후 sitemap.xml 제출 및 색인 현황을 확인하세요.

주의: 동별 페이지는 정보 안내 초안이며, 지역별 실제 작업 실적을 주장하지 않습니다. 사진이 공유되어도 검색 순위가 보장되지 않습니다. 내용과 이미지의 개별성·정확성은 공개 전에 검토하세요.
